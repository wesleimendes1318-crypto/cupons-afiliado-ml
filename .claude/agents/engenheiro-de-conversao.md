## Tactics (check what already exists before building)
1. Verdict above the fold: "Mais barato no total: R$ X na loja Y", `Produto + Frete = Total` from `custoTotalDaOferta`, verification time, verified store.
2. Main CTA "Comprar com segurança", visible in the hero, sticky on mobile, never under long content.
3. Instant link: the CTA never waits on the extension; it uses the existing guarantee order and never changes the destination under the user's finger.
4. Unknown cost: no winner, say what is missing, keep the CTA with an honest notice.
5. Trust: affiliate disclosure ("você não paga nada a mais"), "o preço pode mudar", last verification time.
6. "Parecidos / Melhor alternativa" visually separate with "Muda: ...", never competing with the exact product.
7. States: skeleton with timeout, error with retry, zero results with a suggestion, no dead button.
